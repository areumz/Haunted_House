# Haunted House 👻

A Three.js project created while following Three.js Journey.
Three.js Journey 강의를 따라 제작한 Three.js 프로젝트입니다.

## Features

- Haunted house scene
- Animated ghosts
- Realistic lighting and shadows
- Fog effects

- 유령의 집(Haunted House) 씬 구현
- 애니메이션이 적용된 유령 효과
- 사실적인 조명 및 그림자 표현
- 안개(Fog) 효과 적용

## Tech Stack

- Three.js
- Vite
- JavaScript

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
